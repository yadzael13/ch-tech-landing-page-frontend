# ADR-0001

## Título

Adoptar Next.js como framework frontend.

---

## Estado

Aceptado

---

## Fecha

2026-08-01

---

## Contexto

El proyecto requiere un framework moderno que permita:

- SEO
- Server Components
- Escalabilidad
- Excelente experiencia de desarrollo

---

## Decisión

Se utilizará Next.js con App Router.

---

## Alternativas

React + Vite

Angular

Nuxt

---

## Consecuencias

### Positivas

- Excelente SEO

- Ecosistema maduro

- Muy utilizado en la industria

### Negativas

- Mayor complejidad

- Curva de aprendizaje
